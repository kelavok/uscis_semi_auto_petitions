# Universal citation and exhibit-list rules

- Every exhibit used by a drafted section must include an introductory exhibit reference and the line: `Within the Exhibit, the following documents are attached:`
- Follow that line with a complete numbered list of the documents covered by the section. When another drafting unit adds material to the same Exhibit, return the updated list for the material covered so far.
- Use the criterion-aligned exhibit number: Exhibit 0 for general documents, Exhibit 0-1 for recommendation letters, Exhibits 1 through 10 for EB-1A Criteria i through x, and Exhibit 11 for the employment plan.
- Use the item-number prefix supplied in the prompt. Never carry an item prefix from another criterion into the current section.
- Citation form: `(Please refer to Exhibit 2, page PAGE: 2.1.1 - Concise English document title, original and English translation.)`
- Keep `PAGE` until final pagination. Do not use `XX`, a raw filename, a filesystem path, or a document ID in petition prose.
- In `used_documents`, replace technical/source filenames with short, descriptive English `document_title` values. These titles are saved back to the deterministic document index after validation.
- Keep one title for an original/translation bundle and state `original and English translation` in the exhibit list/citation when both are supplied.
