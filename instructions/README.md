# Instructions

Файлы в этой папке должны загружаться на каждом запуске. Они являются настраиваемой частью системы, а не документацией к зашитой в Python логике.

Разделение ответственности:

- `universal/` — правила, общие для всех task types;
- `task_types/<task_type>/task_rules.md` — правила конкретного типа задачи;
- `task_types/<task_type>/opening_context.md` — начало каждого полного prompt;
- `task_types/<task_type>/sections/` — правила конкретных drafting steps;
- инструкции конкретного кейса лежат внутри case folder;
- runtime instruction передается отдельным файлом через CLI.

Содержательные конфликты между уровнями не должны разрешаться молча.
