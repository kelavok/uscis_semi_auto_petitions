# Two-phase criterion, phase 2

Draft the second evidentiary phase for one episode.

Use this for:

- contribution: major significance/impact evidence;
- leading/critical role: distinguished reputation of the organization;
- salary: comparison with indexed market, occupational, geographic, or industry sources.

Rules:

- connect phase 2 to the same episode as phase 1;
- use indexed sources and identify any weak comparison basis;
- do not invent external statistics or reputation facts.
