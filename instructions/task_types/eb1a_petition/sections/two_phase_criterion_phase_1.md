# Two-phase criterion, phase 1

Draft the first evidentiary phase for one episode.

Use this for:

- contribution: contribution existence, nature, and adoption/use facts;
- leading/critical role: employment, role, responsibilities, and critical/leading facts;
- salary: compensation fact, amount, period, source, and currency.

Rules:

- do not draft the second-phase analysis in this step;
- use only selected documents;
- flag missing comparison/significance/reputation evidence for phase 2.
