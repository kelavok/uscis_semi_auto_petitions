# Opening context intake

Purpose: give the LLM the case context and ask it to read only.

The prompt must include:

- task type and drafting goal;
- beneficiary name, field, specialization, and preferred reference style;
- available CV/profile/education text;
- available employer/recommendation/media text if selected for context;
- a strict instruction not to draft memorandum sections yet.

Expected response: short acknowledgement, possible intake notes, and questions for missing context. No petition prose.
