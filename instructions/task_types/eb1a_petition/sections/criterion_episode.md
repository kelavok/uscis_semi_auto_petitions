# Criterion episode

Draft one criterion episode per prompt.

Rules:

- use only documents selected for this episode;
- write in the template style for the relevant criterion;
- produce the complete document/index list required by the supplied exhibit-number and item-prefix plan;
- use concrete names, dates, figures, organizations, selection rules, links, and other measurable details found in the evidence;
- enumerate relevant media sources individually rather than compressing them into a generic sentence;
- put every unsupported or weak factual statement in `unsupported_claims` or `quality_flags`;
- if a document is visual or not machine-readable, refer to its indexed title and user-provided description only.
