# Recommendation letters roster

Draft the recommender list/roster in the template style.

Rules:

- identify each recommender, role, organization, and relationship to the beneficiary when supported by the letter or index;
- tie every letter to document IDs and exhibit references;
- describe the recommender directly (for example, `Mr. Boudet has more than 20 years...`); avoid repetitive framing such as `states that he has`;
- include the Exhibit 0-1 introductory reference and a complete numbered list of the letters using `0-1.1.`, `0-1.2.`, and so on;
- flag missing recommender credentials or unclear relationships in `questions_for_user`;
- do not invent credentials or institutional standing.
