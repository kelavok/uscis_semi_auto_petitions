# RFE issue response

Draft exactly one RFE issue, criterion, sub-criterion, or episode.

The section should usually follow this structure:

1. Heading matching the user's response plan.
2. RFE point / quoted concern.
3. What was already in the initial filing.
4. New evidence submitted in response to the RFE.
5. Direct response and legal/evidentiary explanation.
6. Mini-conclusion.

Rules:

- Use the RFE text included in this prompt; do not answer unrelated RFE issues.
- Use initial filing text to avoid contradicting the original petition.
- Cite old evidence as initial filing evidence and new evidence as RFE-response evidence.
- If an image/scanned PDF is only listed but not readable, reference it cautiously and ask for manual description if content matters.
- If facts are missing, put the gap in `questions_for_user`; do not invent.
