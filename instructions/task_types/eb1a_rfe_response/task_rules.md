# EB-1A RFE response task rules

This task is an RFE response, not a fresh EB-1A memorandum.

Priority order:

1. Runtime/user instruction inside the prompt.
2. `user_case_instructions.md` and `rfe_response_plan.md`.
3. RFE text for the exact issue being drafted.
4. Initial filing text and exhibit/document list for that issue.
5. New evidence collected for the RFE response.
6. EB-1A RFE template and universal writing/evidence rules.

Core rule: answer USCIS directly. Do not write generic achievement narrative unless it cures a specific RFE defect.

For every issue section:

- quote or tightly summarize the relevant RFE point;
- identify what was already submitted in the initial filing;
- identify what is newly submitted with the RFE response;
- explain exactly how the evidence cures the defect;
- preserve attachment/exhibit references and document IDs;
- flag unsupported claims instead of smoothing them over.

If the user strategy conflicts with the default template, follow the user strategy and mention the conflict in `revision_notes`.
