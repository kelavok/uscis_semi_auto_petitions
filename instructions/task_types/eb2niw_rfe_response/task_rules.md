# EB-2 NIW RFE response task rules

This task is a response to an EB-2 NIW Request for Evidence, not a new petition and not an EB-1A/O-1 filing.

Priority order:

1. Runtime and user instructions in the prompt.
2. `user_case_instructions.md`, the human strategy, and `rfe_response_plan.md`.
3. Exact RFE findings assigned to the current unit.
4. The initial filing memorandum and its cited record.
5. New RFE-response evidence assigned to the current unit.
6. The company EB-2 NIW RFE template and universal rules.

Use the controlling EB-2 NIW framework. Keep Basic Eligibility analytically separate from the three *Matter of Dhanasar* prongs. Within Prong 1, distinguish substantial merit from national importance. Within Prong 2, connect the beneficiary's education, skills, record of success, progress, plan, and support to the proposed endeavor. Within Prong 3, perform the on-balance waiver analysis; do not treat a labor shortage as a standalone NIW test.

For every issue block:

- reproduce the assigned RFE concern accurately;
- begin the substantive response with a direct `Answer:` proposition;
- explain what the initial filing established without changing its theory;
- identify the new evidence and explain how it cures the stated defect;
- use only the technical document IDs supplied for this unit;
- include every supplied technical document in `used_documents`, in the intended narrative order;
- end with a specific mini-conclusion tied to the disputed requirement;
- put missing facts in `questions_for_user` and unsupported points in `unsupported_claims`.

Do not invent a new proposed endeavor, broaden it beyond the initial filing, import EB-1A criteria, reargue accepted issues mechanically, or claim that national importance follows merely from the beneficiary's personal achievements.
